## Featured projects

### [RAW — Agricultural WhatsApp Automation](https://github.com/avin-cyborg/RAW-Read-Analyze-Write-bot-for-crop-dealers-in-whatsapp)

A locally deployed bot used by **1,000+ agricultural brokers across Telangana** to process crop market offers.

- Extracts offer details with Gemini, translates them, and routes updates to relevant buyer groups.
- Uses queued processing, operational logs, and a local dashboard to manage daily workflows.

**Built with:** JavaScript, Node.js, Express, Gemini API, WhatsApp Web integration, Socket.IO.

### [Turing Arena — AI Decision-Making Benchmark](https://github.com/avin-cyborg/Turing-Arena)

A platform for comparing language models with Stockfish through competitive chess. The focus is decision quality, rule compliance, and consistency under constraints.

- Supports multiple AI providers through modular player adapters.
- Broadcasts live game state through WebSockets, with move validation and retry handling.

**Built with:** Python, FastAPI, WebSockets, python-chess, Stockfish; SvelteKit and TypeScript frontend in development.

[View the basic demo](https://turing-arena-frontend.onrender.com/)

### [Matrix — Agent-Based Software Development](https://github.com/avin-cyborg/Matrix)

An experimental system that coordinates management, development, and QA agents around a software task. I'm exploring how agents can plan, build, and review software together.

**Built with:** Python, LLM integration, agent orchestration.
